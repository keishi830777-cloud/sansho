# Ver.2 素材

図形・効果音はすべて、このゲーム向けの自作仮素材です。

| 現在の素材 | 差し替え箇所 |
| --- | --- |
| ライム・ピンク等のオウオ | `src/art.ts` の `ouo()`。通常、圧縮、叫び、飛行の姿 |
| 川、宇宙、惑星、カーニバルの輪 | `src/shot-renderer.ts` |
| 上昇音、鼓動、発射、連鎖、決壊 | `src/audio.ts` |
| 結果カード | `src/main.ts` の `resultCanvas()` |
| OGP | `scripts/generate-ogp.mjs` |
| アイコン | `public/favicon.svg` |

今後、架空の「オウオ」「カーニバァァル」のオリジナル掛け声を収録すると、発射の気持ちよさを強められます。画像差し替え時もローカル配信を維持してCanvasをCORSで汚染しないこと。ミュート、音量、動き軽減、ユーザー操作によるAudioContext開始を維持してください。
