# 30秒版の差し替え素材

素材はゲーム用にコードで作った仮素材です。他プロジェクトの素材は使っていません。

| 素材 | 接続箇所 |
| --- | --- |
| 通常、巨大、顔向け、ぷにぷにダンスのオウオ | `src/carnival/art.ts` の `ouo()` |
| 落下、阻止、跳ね返りのバケツ | `src/carnival/art.ts` と `Renderer.signal()` |
| 川、水流、密集背景、お祭り背景 | `Renderer.background()` |
| バケツおじさん、研究員のカットイン | `Renderer.eventArt()` |
| オウ、オウオ、オウオウオ、サンショウオウオ、カーニバァァルの録音 | `Sound.cue()` と `voice()` |
| 通常、コンボ追加、フィーバーの音楽ステム | `Sound.tick()` |
| 阻止、水しぶき、フィニッシュ効果音 | `src/carnival/audio.ts` |
| ストーリーズ用結果カード | `src/carnival/share.ts` |
| OGP | `scripts/carnival-ogp.mjs` |

図形は大きい頭、小さい目、短い4肢と扁平な尾を維持します。色で在来／外来／交雑を示さないこと。外部画像へ変更する場合もCanvasのPNG出力をCORSで汚染しないように配信します。音声差し替え時も音量、ミュート、ユーザー操作による初期化を維持します。掛け声は架空であり実際の鳴き声という説明は付けません。

一発版の素材・ソースはそのまま保持し、公開HTMLを `public/one-shot/` に保存しています。
