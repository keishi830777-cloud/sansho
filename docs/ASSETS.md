# 素材の差し替え一覧

現在の図形・画像・サウンドは、このゲーム用にコードで作成した仮素材です。外部の画像や録音は流用していません。

| 現在 | 差し替え案 | 接続箇所 |
| --- | --- | --- |
| Canvasのオウオ（4肢・広い頭・小さな目・扁平な尾） | 通常／ダンス／正面／巨大のスプライト | `src/art.ts` の `ouo()` |
| Canvasのバケツ | 通常／阻止時／落下時の画像 | `src/art.ts` の `bucket()` |
| 曲線・石・水流の川 | 背景レイヤーと軽いループ素材 | `Renderer.background()` |
| 図形のバケツおじさん | おじさんの投擲アニメーション | `Renderer.drawEvent()` |
| 文字表示の研究員 | 研究員キャラのカットイン | `Renderer.drawEvent()` / イベントバナー |
| 合成音の掛け声 | オウ、オウオ、オウオウオ、サンショウオウオ、カーニバァァルのオリジナル録音 | `Sound.cue()` |
| オシレーターのBGM | 通常・成功コンボ・混乱・フィーバーの短い音楽ステム | `Sound.tick()` |
| 合成の水しぶき／フィニッシュ | オリジナル効果音 | `Sound.miss()` / `finish()` |
| Canvas結果画像・OGP | 同じキャラ素材を反映したカード | `src/share.ts` / `scripts/generate-ogp.mjs` |
| SVG favicon | オリジナルアイコン | `public/favicon.svg` |

画像を使う場合も種類ごとの色分けで在来・外来・交雑を断定しないこと。素材のローカル配信を維持し、Canvasの画像保存を妨げるCORS汚染を避けます。音声は音量・ミュート・ユーザー操作による初期化を維持します。実在の鳴き声という説明は付けません。
