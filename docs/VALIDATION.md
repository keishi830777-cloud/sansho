# 30秒カーニバル版・検証

2026-10-12、Node.js 24.19.0、Linux上のChromium。

- npmによる依存導入、TypeScript検査、Viteビルド、Pages用ファイル生成成功。
- モデルテスト17件（30秒版9件＋保持した一発版8件）成功、スキップ0。
- 実時間のPCプレイで、約31.422秒（30秒操作＋1.45秒フィニッシュ）で結果表示。65個を連続阻止、見逃し0、侵入0でも最終フィーバー発生。
- マウス、390pxスマホのタッチ、同一バケツの二重加点防止、見逃し時の世代・混乱・密集、リトライ、一時停止、設定保存、ベスト保存を確認。
- localStorageが拒否された320px幅でも起動。iPad横画面1024×768で横はみ出しなし。
- 結果PNGは1080×1920。学習4章と出典3リンクを確認。ネイティブ画像共有はOS共有シートをスタブ化しファイル引数を確認。
- 旧一発版のHTMLを `/one-shot/index.html` で起動確認。開発サーバーのディレクトリURLはSPAへ戻るため、リンクは明示的にindex.htmlを指定。
- 環境省の交雑の解説を再取得し本文確認。出典PDF・予防原則は同じセッションで既に本文確認済みの資料。

実際のiPhone Safari／Android Chrome端末、共有先アプリでの投稿完了、耳で聞く音量・効果音の調整、低スペック端末の60fps、面白さのユーザーテスト、学習内容の専門家監修は未実施です。Canvasの負荷を抑えるため群れ115体、粒子150個、DPR2を上限にしています。

公開用の1ページHTMLでも、375×667でキーボード加点、30秒終了、見逃しとパニック、フィーバー、PNG、X投稿文章（実際の投稿は行わない）、学習、リトライ、一時停止からの設定、一発版の保持を確認しました。公開用ビルドに開発用状態APIは含まれていません。

最大115体で描画命令と疑似物理を120フレーム測定し、このコンテナでは平均約2.24ms、95パーセンタイル約3.30ms/描画でした。密集時の奥の個体は頭部だけ描いて負荷を減らしています。この値は実機のGPU描画時間やfpsを保証するものではありません。
