# 学習内容と出典

2026-10-12に以下の環境省ページ／PDFの本文を取得・確認し、学習画面にリンクしました。

1. [チュウゴクオオサンショウウオと交雑種](https://www.env.go.jp/nature/intro/2outline/attention/chugokuoosanshouo.html)
   - 日本固有のオオサンショウウオとの交雑、子孫の繁殖能力、長期的な遺伝的かく乱の影響を記載。
   - 交雑が進むにつれ外見での判別が難しくなることと、遺伝子検査の必要性を確認。
2. [特定外来生物の同定マニュアル・両生類 PDF](https://www.env.go.jp/nature/intro/2outline/manual/4hp_ryoseirui.pdf)
   - 末尾のオオサンショウウオ属の節（3ページ構成）、特に2/3ページの判別に関する注意を確認。
   - 形態の判別資料をゲームの色分け・攻撃対象の判断へ転用しない。
3. [外来種問題について・外来種被害予防三原則](https://www.env.go.jp/nature/intro/2outline/invasive.html#sec4)
   - 「入れない」「捨てない」「拡げない」、逃がさない／放さないという原則を確認。

学習文は上記を要約したものであり、環境省の監修・推奨を受けた作品という意味ではありません。専門家の監修は未実施です。開発仕様の要請に沿い、遺伝子解析を万能の判定法と表現せず、調べる指標・比較資料なども含めた専門的判断の必要性を付記しています。確認できていない個体数・侵入割合・繁殖速度などの具体値は掲載していません。

## 演出と事実の区別

- 操作対象は放流前のバケツ。外来個体・交雑個体を攻撃しません。
- 見逃し0の場合は世代進行や交雑進行を発生させません。成功時の祝祭はコンボに応じて別に発生します。
- 侵入後の群れは在来・外来・交雑が混在する状況を表し、色や模様で分類しません。
- 「20年後」等は長い年月の早送りの演出値であり、成熟年齢・繁殖周期などの推定値ではありません。
- 群れやパニック指数はコミカルな演出です。交雑が爆発的な個体数増加を必ず引き起こすとは説明しません。
- 実在の動物を勝手に動かす・放す・捕獲する・駆除する行為を勧めません。
