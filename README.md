# サンショウオウオカーニバル

**オウオ大増殖パニック / 30秒で、川がカーニバル。**

[30秒版を遊ぶ](https://keishi830777-cloud.github.io/sansho/) · [一発オウオ砲](https://keishi830777-cloud.github.io/sansho/one-shot/index.html)

指定された30秒・バケツ阻止・交雑問題の仕様に沿うゲームです。今回の実装は `src/carnival/` に独立して置き、一発版のソースを保持しています。一発版の動作する1ページHTMLは `public/one-shot/` に保存しました。

## 遊び方

- 「カーニバル、開幕！」から開始。落ちてくる**バケツ**をタップ／クリックして放流を阻止。
- 阻止100点。5・10・15・20コンボで倍率1.5・2・2.5・3倍。見逃すと現在のコンボが途切れます。
- 失敗しても30秒間続きます。阻止スコアと混乱の「オウオパニック指数」は別です。
- 24秒からフィーバー、最後の約1秒まで新しいバケツが出現。最後は1.45秒のフィニッシュから結果画面へ。
- キーボードではCanvasへフォーカスしてSpaceで一番下のバケツを阻止します。
- タブを離れると一時停止。復帰後に「つづける」。30秒は一時停止を除く実プレイ時間です。

## 気持ちよさの実装

- 各タップで、バケツの跳ね返り・広がるリング・加点文字・紙吹雪・仮掛け声を同時に返します。
- 5コンボごとの大きな文字、連続成功ほど多重になる旋律・パーカッション・仮音声。
- 巨大オウオ、団体旅行、研究員、バケツおじさんの短い連続投下、フィーバー。
- 群れは近隣グリッドによる押し合い、顔を向ける動き、跳ねるダンス、密集。最大115体、粒子最大150個。
- 混乱が大きいと背景にも群れの演出。操作対象のバケツは群れ・カットインより上へ描画します。
- フィーバーは背景、音楽、紙吹雪を変化させ、完全阻止のプレイでも発生します。
- 激しい点滅は使いません。画面揺れ・動きの軽減、音量・ミュートを設定できます。

## 起動・検証

Node.js 22.12以降（検証済み24.19.0）、npm。外部APIキー・DB・外部フォントは不要です。

```sh
cd /workspace/sansho
npm ci
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
```

開発サーバー起動中に `npm run test:browser`。Chromiumは `/usr/bin/chromium`、別環境では `CHROMIUM_PATH` を指定します。実時間30秒のPCプレイとタッチ入力、リトライ、画像保存、共有引数、学習ページ等を確認します。

本番配信の検証は `npm run preview` → `npm run test:production`。Pages用の検証は `npm run build:pages` → `npm run serve:pages`（4190）→ `npm run test:pages`。サーバーは別ターミナルで起動してください。スクリーンショットはGit対象外の `test-results/` へ保存します。

## 科学的な扱い

攻撃対象は動物でなくバケツ。侵入なしなら交雑や世代経過の演出は発生させません。侵入後の群れは在来・外来・交雑が混在する状況ですが、色や外見で種類を判定しません。群れの密集は長い年月を早送りした誇張表現で、実際の繁殖速度・個体数推移ではありません。

リザルトから、遺伝的特徴の保全、外見の判別の限界、移動・放流を避ける行動を学べます。環境省の確認済み資料へリンクしています。確認した内容は `docs/SCIENCE.md`。

## 公開

`npm run build:pages` で `.pages/` に配信ファイル（1ページHTML、OGP、一発版）を生成します。その内容を `gh-pages` ブランチに配置してGitHub Pagesで配信します。別の公開先は `STATIC_SITE_URL=https://example.com/path/` を指定します。

OGP再生成は開発サーバー起動中に `npm run assets:ogp`。通常の `dist/` はドメイン直下で配信します。Git worktreeは不要です。各クラウドタスクは隔離されているので既存のチェックアウトを使ってください。プロセスはタスクの再開時に起動し直します。
