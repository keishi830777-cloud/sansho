# サンショウオウオカーニバル / 一発オウオ砲

**指を離すと、宇宙が始まる。**

[ゲームを遊ぶ](https://keishi830777-cloud.github.io/sansho/)

Ver.2は一発勝負の長押し・発射ゲームです。バケツや30秒プレイのVer.1から作り直しました。

## 遊び方

1. 「押し続けろ」を長押し。オウオと川に圧をためます。
2. 押したまま指を左右へ動かすと発射方向が変わります。空の輪を狙います。
3. **ピンクになったら離す**。92%以上のオウオ圧で限界突破。群れが一気に噴き上がり、輪に当たるたびに連鎖してさらに上昇します。
4. ためすぎると「川、抜けた。」。早すぎると「ぴょ。」。もう一発はすぐに挑戦できます。

限界までの時間は毎回3.2〜4.4秒で変わります。秒数の暗記ではなく、色・圧・顔・音で判断します。一発のフライトは最大8秒。到達高度と連鎖、限界突破でスコアを計算します。飛行中に追加の操作は不要です。

キーボードではボタンにフォーカスして **Space / Enterを押し続け、離して発射**。保持中の左右矢印で狙いを調整します。支援技術のクリック操作では1回で保持開始、もう1回で発射します。タブを離れる・タッチがキャンセルされると、保持は失敗扱いにせず中止します。

## 開発

Node.js 22.12以降（検証環境24.19.0）、npmを使用します。外部APIキー・DBは不要です。

```sh
cd /workspace/sansho
npm ci
npm run dev
```

```sh
npm test
npm run typecheck
npm run build
```

テスト用Chromiumが `/usr/bin/chromium` にある環境では、開発サーバーを起動して `npm run test:browser` を実行できます。別のChromiumは `CHROMIUM_PATH` で指定します。`TEST_URL` で検証対象を変更できます。iPhone・iPad実機の検証は別途必要です。

## 構成

- `src/shot.ts`：描画に依存しない一発の状態、可変限界、圧、狙い、飛行物理、輪の衝突、スコア。
- `src/shot-renderer.ts`：スクロールする川〜宇宙、最大150体の群れ、粒子、圧の変形、決壊。
- `src/main.ts`：タッチの捕捉、画面と状態、キーボード、保存、PNG、ネイティブ共有。
- `src/art.ts`：オウオの図形素材。
- `src/audio.ts`：上昇する持続音、加速する鼓動、発射・連鎖・決壊の合成音。
- `src/storage.ts`：設定の読み書き。新しいベストは `ouo-shot-best` に保存し、旧作の得点と混ぜません。
- `tests/shot.test.ts`：一発判定、限界、失敗、飛行、連鎖、取消、結果の不変性。
- `scripts/browser-test.mjs`：実時間のマウス操作とモバイルのタッチ操作。

## 公開

```sh
npm run build:pages
```

`.pages/` の `index.html`、`ogp.png`、`.nojekyll` を `gh-pages` ブランチに配置します。GitHubのSettings → PagesはDeploy from a branch、gh-pages、/ (root)です。HTML内にJS・CSS・アイコンを内包するため `/sansho/` 配下でも起動します。

別の公開先は `STATIC_SITE_URL=https://your-domain.example/path/ npm run build:pages` を指定します。`dist/` をそのまま配信する場合はドメイン直下で配信し、`PUBLIC_SITE_URL` にドメインのルートURLを設定します。

結果は1080×1920 PNGで保存できます。画像共有が利用可能ならネイティブ共有、それ以外は文章共有・コピー・手動コピーへ切り替えます。共有先アプリ側の実際の受け渡しは端末依存です。公開URLは画像と共有文章に含まれます。

OGPの再生成は開発サーバー起動中に `npm run assets:ogp`。デプロイ前には新しいOGPを含めて再ビルドします。

## このゲームについて

用語を引き継いだ架空のオウオ宇宙のゲームです。圧・連鎖・飛行・群れの演出は実際の生態を説明するものではありません。素材・音声は自作の仮素材です。

現在の目標は一発の気持ちよさとリトライの速さです。実機での音量・触感・難易度の調整、オリジナル掛け声、輪の配置を変えたチャレンジの追加が改善候補です。
